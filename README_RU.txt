ОСГ КОНТРОЛЬ — инструкция

Содержимое:
- index.html — интерфейс приложения
- app.js — расчёты
- manifest.webmanifest — параметры установки
- sw.js — кэширование для работы после первого открытия
- icon.svg — значок

ВАЖНО:
Это готовый пакет исходных файлов PWA, но он ещё не опубликован в интернете.
Чтобы другие люди могли установить приложение, файлы нужно разместить на HTTPS-хостинге.
Подойдут статические хостинги, например GitHub Pages, Netlify или Cloudflare Pages.
После публикации отправьте коллегам HTTPS-ссылку.

Установка:
iPhone (Safari): открыть ссылку → «Поделиться» → «На экран Домой».
Android (Chrome): открыть ссылку → меню браузера → «Установить приложение» или «Добавить на главный экран».

Приложение не требует аккаунта и не отправляет введённые даты на сервер.
Для работы Service Worker требуется HTTPS (или localhost при тестировании).

О логике:
Порог ОСГ применяется как минимальная доля полного срока годности, которая должна оставаться к утренней отгрузке.
Дата снятия вычисляется как дата окончания срока минус ceil(полный срок × процент / 100).
Проверьте формулу по официальному регламенту магазина перед использованием на работе: в исходной таблице процент описан как «процент отгрузки со склада», что может не совпадать с правилом снятия с витрины.
